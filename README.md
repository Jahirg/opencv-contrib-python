This is a test implementation of point-of-interest algorithms using various algorithms in OpenCV.
The opencv-contrib-python package is used, and the SURF algorithm is enabled.
Requirements:
Python 3.12.9
PyQt5
NumPy
OpenCV-contrib-python 4.14.0.94 (modified version available in ".whl")

To install it, use the Windows Command Prompt and navigate to the folder where the file is located.
opencv_contrib_python-4.14.0.94-cp312-cp312-win_amd64.whl

pip install opencv_contrib_python-4.14.0.94-cp312-cp312-win_amd64.whl --force-reinstall

ready to use.
